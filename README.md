# Trevor Renner

Infrastructure Security Engineer at [MoonPay](https://www.moonpay.com), based in Vancouver, BC.

I build guardrails and paved roads for detection engineers and analysts: secure platforms, dependable telemetry, and tools that make investigation easier. My work spans cloud infrastructure, workload identity, secrets management, and automation across GCP and AWS.

I approach security engineering as a systems problem. The goal is to turn recurring operational friction into reusable capabilities: make the secure path straightforward, give teams the context to make sound decisions, and build infrastructure they can operate and extend. I connect platform design to the people using it and the detection outcomes it needs to support.

## Research and Writing

I completed the SANS ISC DShield internship, investigating attacker behavior through honeypot telemetry. That work led me to explore whether threat actors could use agentic probing to fingerprint honeypots by exposing inconsistencies in shell emulation. Controlled experiments produced a candidate response pattern; whether the observed attackers used agents or recognized the honeypot remains an open question.
